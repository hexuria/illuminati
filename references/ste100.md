# Controlled prose (working subset)

Use this file when you write the first rung. It is a practical subset for agent explanations. It is not a copy of ASD-STE100, and it is not a compliance claim. The official specification and dictionary are published by ASD at https://www.asd-ste100.org/. If you do not have that document open, say that the draft is STE-style, not verified against the dictionary.

The goal is one reading. The reader should not have to pick among meanings.

## Before you write

Write the question in one sentence. List the nouns and verbs you will use. That list is the synonym lock.

## Rules

1. **One idea per sentence.** If a sentence has two verbs that do different jobs, split it.
2. **Short sentences.** A descriptive sentence has at most 25 words. An instruction has one action. `scripts/verify_ste` fails a sentence over 25 words.
3. **Name the actor.** Start with the thing that acts: "The shell starts the writer." Do not hide the actor.
4. **Active voice.** Use a simple present verb for a fact. Use an imperative for a step. A passive line is allowed only when the actor is unknown. The checker prints passive hits as warnings. Warnings do not fail the file, because the heuristic is noisy.
5. **Simple words.** Prefer a short common word when it has one meaning. Keep a technical term when the short word would lie. Define that term once.
6. **Synonym lock.** After you pick a word for a thing, do not use another word for that thing. "Send" and "transmit" and "emit" are three words. Pick one. If the source text uses two names for one object, pick one name, define it, and stay with it.
7. **Define once.** The definition is one sentence: "Standard output is file descriptor 1." Later sentences use the term. They do not redefine it.
8. **No metaphor as the mechanism.** You may name a common category ("a queue") only if you also say what the thing is ("a buffer in the kernel"). Do not stop at the metaphor.
9. **Procedures.** Number the steps. Put the condition before the action. One action in each step.
10. **Warnings.** Put a warning in its own paragraph, before the step it protects. Do not put the warning in the same sentence as the action.

## Deny-list

The checker fails the file if any of these appear as whole words. Case does not matter. A longer word that merely contains the letters is not a hit.

| Do not write | Write instead |
| --- | --- |
| various | Name the items, or write "more than one". |
| etc. | Stop the list, or name the last item you mean. |
| appropriate | State the real condition. |
| simply | Delete the word. |
| just | Delete the word. |

## What the checker does not prove

`scripts/verify_ste` does not read the official dictionary. It does not score style. A clean report means only this: no sentence is over 25 words, and the deny-list words are absent. Passive-voice lines are printed as warnings. You still have to keep the synonym lock and the one-idea rule yourself.
